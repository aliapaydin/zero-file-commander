## English (en-us)

### Short description
The power of a classic dual-pane commander with a modern Windows 11 design: tabs, a smart copy queue, quick previews for every file, SFTP/FTP/NAS connections and Git status. Open source, no ads, no data collection.

### Description
```
Zero File Commander brings the speed of classic dual-pane file managers to a modern Windows 11 design. Built for keyboard lovers, comfortable with a mouse too.

DUAL PANE AND TABS
• Two panes with tabs that are restored when you reopen the app
• F2–F8 shortcuts, Insert to mark, type to filter instantly
• Command palette (Ctrl+K), Windows 11-style context menu, ribbon, folder tree and drive bar

SMART COPYING
• Copy/move queue with pause, resume, speed and time remaining
• Name conflicts never block the queue; resolve them at the end in one click
• Multiple windows (Ctrl+N), send between windows and monitors, a file shelf

PREVIEW EVERYTHING
• Images, video, music, PDF and Word/Excel/PowerPoint documents
• Syntax-highlighted code: Python, SQL, C#, JavaScript, HTML, JSON, YAML, PowerShell, DAX, Power Query and more
• Jupyter notebooks with outputs and charts
• CSV, TSV and Parquet as tables
• Power BI (PBIX, PBIT, PBIP, TMDL): pages, tables, measures and relationships

CONNECTIONS
• NAS and network shares (SMB), SFTP, FTP and FTPS
• OneDrive, Google Drive, Dropbox, iCloud and Box folders; online-only files are marked
• Passwords stored in the Windows Credential Locker; SFTP host key verification

FOR DEVELOPERS
• Git branch and file status, "Open in VS Code"
• Browse ZIP archives like folders, batch rename, folder compare and sync, content search

SAFE AND PRIVATE
• Deletes go to the Recycle Bin by default; permanent delete only after confirmation
• Optional 4-digit PIN lock
• No telemetry, no ads, no data collection
• Open source (MIT): github.com/aliapaydin/zero-file-commander

The interface is currently in Turkish; English is coming.
```

## Gönderim sırasında sorulacaklar

### Kısıtlı yetenek gerekçesi (runFullTrust)
Partner Center → **Submission options → Restricted capabilities** alanına:
```
Zero File Commander is a desktop file manager built with WinUI 3 / Windows App SDK. runFullTrust is required to perform user-initiated file operations anywhere on the file system (copy, move, rename, delete to Recycle Bin via the Windows Shell), to host Windows preview handlers for Office and PDF files, to show a system tray icon, and to connect to the user's own SFTP/FTP/SMB servers. The app does not collect or transmit user data.
```

### Yaş derecelendirmesi (IARC anketi)
- Kategori: **Uygulama** (oyun değil).
- Şiddet, cinsellik, kumar vb. sorularının hepsine **Hayır**.
- "Kullanıcılar arası etkileşim / içerik paylaşımı": **Hayır**.
- "Kişisel bilgi paylaşımı": **Hayır**.
- "Sınırsız internet erişimi / web içeriği": **Evet** de. İsteğe bağlı indirme yöneticisi kullanıcının verdiği adreslerden dosya indirebiliyor.
- Beklenen sonuç: **3+ / Herkes**.

### Fiyat ve kullanılabilirlik
- **Ücretsiz**, tüm pazarlar.
- Görünürlük: önce **Gizli (yalnızca bağlantıyla)** seçip kendi bilgisayarında Store'dan kurarak test edebilirsin. Sonra **Herkese açık** yaparsın.

### Özellikler
- Kategori: **Yardımcı programlar ve araçlar** (Utilities & tools), alt kategori: **Dosya yöneticileri**.
- Sistem gereksinimleri: klavye ve fare önerilir.
